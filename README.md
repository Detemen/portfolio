# portfolio

Source for [detemen.github.io/portfolio](https://detemen.github.io/portfolio/) — a single-page landing site listing every public project, each with a real working link (live demo where one exists, source always).

Plain HTML/CSS, no build step, deployed via GitHub Pages straight from `main`.

## Updating

Edit `index.html`, commit, push to `main` — Pages picks it up automatically.

See [Project Atlas](https://detemen.github.io/project-roadmap-site/) for a filterable, browsable version of the same project list.
